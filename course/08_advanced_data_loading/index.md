# Chargement de données avancé

On a déjà vu [comment charger les données d'une page ou d'un
layout](../01_sveltekit_basics/06_page_data_loading).

Mais en réalité, SvelteKit propose beaucoup d'autres moyens de récupérer des données, ou d'en
envoyer.

> SvelteKit propose une nouvelle méthode de chargement de données depuis sa version 2.27&nbsp;: les
> [fonctions "remote"](https://svelte.dev/docs/kit/remote-functions) (ou "distantes"). Ces fonctions
> sont encore expérimentales, et ne seront pas traitées dans ce cours.
